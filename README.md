# 银龄卫士

面向智慧养老院的端—边—云协同多机器人网络系统。围绕异常行为感知、融合定位、多机器人动态调度和执行避障，提供云端监控、小车监控与护工微信小程序原型。

## 项目结构

源码从原提交包展开到 `src/`，保留各子项目原始中文目录：

| 目录（均位于 `src/`） | 内容 |
| --- | --- |
| 云端监控中心 | FastAPI 后端、Web 监控页面 |
| 云端小车监控中心 | 机器人遥测、事件接口、Web 实时监控 |
| 护工移动端 | 微信小程序、护工业务 FastAPI 后端 |
| 云边协同决策下的面向动态任务插入的异构多机器人协同调度方法 | 调度仿真、曲线与指标 |
| 端边协同感知支撑下的基于UWB弱全局约束多模态后端因子图优化方法 | UWB 与多模态融合定位仿真 |
| 端边协同执行下的面向动态环境的强化学习驱动执行与自适应避障机制 | 执行控制与双车避障演示 |
| 端边协同行为感知下的基于双头时序网络异常行为感知与风险预测方法 | 特征提取、训练与推理脚本 |

原作品 PDF 和介绍视频位于 `√银龄卫士——面向智慧养老院的端边云协同多机器人网络系统/`。大视频使用 Git LFS，克隆后执行 `git lfs pull`。原始 ZIP 保留本地，版本库只跟踪展开源码。后端运行状态、访问日志与现场视频不公开上传，首次启动可能没有演示业务数据。

## 原型启动

推荐 Python 3.11+。三个后端都使用顶层 `app` 包，必须在各自 `backend` 目录启动，并分配不同端口：

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate；Linux/macOS: source .venv/bin/activate
pip install fastapi 'uvicorn[standard]' pydantic

# 在三个独立终端分别进入以下目录执行对应命令
cd src/云端小车监控中心/backend
python -m uvicorn app.main:app --host 127.0.0.1 --port 8001
# src/云端监控中心/backend
python -m uvicorn app.main:app --host 127.0.0.1 --port 8002
# src/护工移动端/backend
python -m uvicorn app.main:app --host 127.0.0.1 --port 8003
```

健康检查：`GET /api/v1/health`。前两个 Web 页面可从相应服务根路径打开。护工端用微信开发者工具打开 `src/护工移动端`，按实际环境调整请求地址及 AppID；本地联调与正式部署的合法域名设置不同。

算法脚本依赖彼此不同，常见依赖为 NumPy、SciPy、Matplotlib；行为识别另需 PyTorch、OpenCV 等及匹配的数据、模型和路径。原始材料不包含完整现场部署环境，不承诺所有训练脚本开箱即用。

## 证据边界与优化计划

详见 [评语自查与 TODO](银龄卫士-评语自查与TODO.md)。当前材料支持仿真、短时双车场景演示及多终端原型，不等价于真实养老院长期运行证明。

优先补齐：事件去重与跨端任务闭环、可重启恢复、同一事件的追踪记录；其次统一仿真实验配置和控制对比条件。双实体车重复试验、跨班次连续运行、急停与人工接管必须在授权场地实测，不能用接口测试或仿真冒充。

目录中历史命名含“强化学习”，不代表已验证 SAC Actor 在实车部署；规则控制演示需要按真实方法标注，不能将不同速度设置下的耗时差异单独归因于算法。

## 安全与隐私

原型接口未具备完整的鉴权、权限隔离和现场安全认证，仅用于可信本地网络开发。不要直接暴露公网。养老数据、面部视频、轨迹与护工资料须授权、脱敏并限制访问；实车联调须保留物理急停和人工护理兜底。
